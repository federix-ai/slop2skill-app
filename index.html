How it works

Turn agent wait time into practice

Your agent gets to work

Slop2Skill notices when Claude Code (or Codex) starts working and opens a slim window next to your terminal, without stealing focus.

A short exercise

Write a function, find the bug or answer a question in Python, Swift or Kotlin. Tests run locally on your Mac.

Grow with the time you win back

Mastery per concept, spaced reviews, a pressure-free streak and a mascot that grows with the hours of waiting you put to use.

Privacy

Stays on your Mac

  • No account, no servers. Progress and statistics never leave your Mac.
  • Never your conversations. From Claude Code hooks it receives the event, the folder and the names of the files touched.
  • Asks before editing ~/.claude/settings.json and makes a backup first. Uninstalling removes only the lines it added.

Install

Up and running in a minute

Requirements

  • macOS 26 or later. The app is available in English and Italian.
  • Claude Code with a Claude subscription, for generated exercises.
  • To run tests: python3, Xcode's command line tools for Swift (xcode-select --install), kotlinc plus a JDK for Kotlin (brew install kotlin openjdk).

First launch

This version is not notarized by Apple yet, so macOS says it can't verify the developer. You only need to allow it once.

  1. Download slop2skill.zip, open it and move Slop2Skill to Applications.
  2. Open the app: macOS blocks it. Dismiss the alert.
  3. Go to System Settings › Privacy & Security and, near the bottom, click Open Anyway next to Slop2Skill.
  4. The mascot appears in the menu bar and a six-step setup starts.
