slopcode

Esercizi di programmazione mentre l'agente lavora. Quando Claude Code pensa, tu ti alleni.

Scarica per macOS v1.0.0 · zip macOS 26 o successivo · Apple Silicon e Intel · gratis

Come funziona

L'attesa dell'agente diventa allenamento

01

L'agente lavora

slopcode si accorge che Claude Code (o Codex) sta lavorando e apre una finestra stretta accanto al terminale, senza rubarti il cursore.

02

Un esercizio breve

Scrivi una funzione, trova il bug o rispondi a una domanda in Python, Swift o Kotlin. I test girano sul tuo Mac.

03

Cresci con il tempo recuperato

Padronanza per concetto, ripassi distanziati, una streak senza ansia e una mascotte che cresce con le ore di attesa usate.

Schermate

Esercizi

Generati da Claude Haiku, con il tuo abbonamento

  • Gli esercizi li scrive Claude Haiku in una sessione nascosta di Claude Code, con il tuo abbonamento: mai con una API key.
  • Generano solo quando nessun agente lavora, entro un tetto giornaliero e settimanale che scegli tu.
  • Ogni esercizio viene verificato prima di arrivarti: la soluzione deve passare i test e il codice iniziale no.
  • Se colleghi un progetto, gli esercizi si ispirano al tuo codice, letto in sola lettura. Il codice dell'esercizio è sempre nuovo.
  • Senza Claude Code c'è comunque un pacchetto di esercizi incluso nell'app.

Privacy

  • Progressi e statistiche restano sul tuo Mac. Nessun account, nessun server di slopcode.
  • Dagli hooks di Claude Code slopcode riceve l'evento, la cartella e il nome dei file toccati, mai le conversazioni.
  • Prima di modificare ~/.claude/settings.json chiede il consenso e ne fa una copia. La disinstallazione toglie solo le righe aggiunte.

Installazione

Requisiti

  • macOS 26 o successivo.
  • Claude Code con un abbonamento Claude, per gli esercizi generati.
  • Per eseguire i test: python3, gli strumenti di Xcode per Swift (xcode-select --install), kotlinc e un JDK per Kotlin (brew install kotlin openjdk). Basta un linguaggio.

Primo avvio

Questa versione non è ancora notarizzata da Apple: al primo avvio macOS dice che non può verificare lo sviluppatore. Si apre una volta sola così:

  1. Scarica slopcode.zip, aprilo e sposta slopcode in Applicazioni.
  2. Apri l'app: macOS la blocca. Chiudi l'avviso.
  3. Vai in Impostazioni di sistema › Privacy e sicurezza e, in fondo, premi Apri comunque accanto a slopcode.
  4. La mascotte compare nella barra dei menu e parte una guida in sei passi.
