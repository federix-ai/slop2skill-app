# slopcode

Esercizi di programmazione mentre l'agente lavora. Quando Claude Code pensa, tu ti alleni: un'app per la barra dei menu di macOS che apre un esercizio breve accanto al terminale, in Python, Swift o Kotlin.

**[Scarica slopcode per macOS](https://github.com/federix-ai/slopcode-app/releases/latest/download/slopcode.zip)** · [pagina del progetto](https://federix-ai.github.io/slopcode-app/)

<p align="center"><img src="assets/finestra.png" width="320" alt="Finestra dell'esercizio"> <img src="assets/menu.png" width="220" alt="Barra dei menu"></p>

## Requisiti

- macOS 26 o successivo.
- [Claude Code](https://docs.anthropic.com/en/docs/claude-code/setup) con un abbonamento Claude, per gli esercizi generati da Claude Haiku. Senza, c'è il pacchetto di esercizi incluso.
- Almeno un linguaggio: `python3`, gli strumenti di Xcode per Swift, oppure `kotlinc` con un JDK.

## Primo avvio

Questa versione non è ancora notarizzata: al primo avvio macOS la blocca. Sposta l'app in Applicazioni, aprila una volta, poi vai in **Impostazioni di sistema › Privacy e sicurezza** e premi **Apri comunque**.

## Privacy

Progressi e statistiche restano sul Mac. Gli esercizi li genera Claude tramite il tuo Claude Code, con il tuo abbonamento e mai con una API key; il codice dei tuoi progetti viene letto solo in sola lettura e solo se lo autorizzi.

Il codice sorgente di slopcode non è pubblico. Questo repository contiene solo la pagina e le versioni da scaricare.
